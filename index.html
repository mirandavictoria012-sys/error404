CAPÍTULO 1

Fundamentos

Las herramientas algebraicas que necesitas para resolver problemas.

1.1 Números reales

Incluyen los números racionales (como \(3/4\), \(-2\), \(0.5\)) e irracionales (como \(\sqrt2\) y \(\pi\)). Se representan en la recta numérica.

Naturales ⊂ Enteros ⊂ Racionales ⊂ Reales

Ejemplo: \(-3\) es entero y racional; \(\sqrt 5\) es irracional.

1.2 Exponentes y radicales

Los exponentes representan multiplicación repetida. Los radicales permiten expresar raíces.

aᵐ · aⁿ = aᵐ⁺ⁿ
√(a²) = |a|

Ejemplo: \(x^2·x^3=x^5\); \(\sqrt{49}=7\).

1.3 Expresiones algebraicas

Combinan números, variables y operaciones. Simplifica términos semejantes y aplica la propiedad distributiva.

a(b + c) = ab + ac

Ejemplo: \(3x+2x-4=5x-4\).

1.4 Expresiones racionales

Son cocientes de polinomios. El denominador nunca puede ser cero; factoriza antes de cancelar factores comunes.

(x² − 9)/(x − 3) = x + 3, x ≠ 3

Importante: la restricción \(x≠3\) se mantiene aunque se simplifique.

1.5 Ecuaciones

Una ecuación afirma que dos expresiones son iguales. Despeja la variable haciendo la misma operación en ambos lados.

2x + 6 = 14 → 2x = 8 → x = 4

1.6 Modelado con ecuaciones

Traduce una situación a una ecuación: identifica la incógnita, define relaciones, resuelve y comprueba en el contexto.

Ejemplo: “un número más 5 es 12” → \(x+5=12\) → \(x=7\).

1.7 Desigualdades

Comparan valores usando <, >, ≤ o ≥. Si multiplicas o divides por un número negativo, invierte el signo.

−2x > 6 → x < −3

1.8 Geometría de coordenadas

Un punto se escribe \((x,y)\). La distancia entre dos puntos se obtiene con Pitágoras.

d = √[(x₂−x₁)² + (y₂−y₁)²]

1.9 Calculadoras gráficas

Sirven para visualizar ecuaciones, localizar intersecciones y comprobar soluciones. La gráfica ayuda, pero revisa también las restricciones algebraicas.

1.10 Rectas

La forma pendiente-intersección es \(y=mx+b\), donde \(m\) es la pendiente y \(b\) el corte con el eje \(y\).

m = (y₂ − y₁)/(x₂ − x₁)

1.11 Modelos con variaciones

Variación directa: \(y=kx\). Variación inversa: \(y=k/x\). La constante \(k\) describe la relación entre variables.

CAPÍTULO 2

Funciones

Una función relaciona cada entrada permitida con exactamente una salida.

2.1 ¿Qué es una función?

Se escribe \(y=f(x)\). El dominio reúne las entradas permitidas y el rango las salidas que se obtienen.

f(x) = 2x + 1

Si x = 3: \(f(3)=2(3)+1=7\).

2.2 Gráficas de funciones

La gráfica muestra todos los puntos \((x,f(x))\). La prueba de la recta vertical ayuda a decidir si una gráfica representa una función.

2.3 Información de una gráfica

Busca intersecciones con los ejes, intervalos donde la función sube o baja, máximos, mínimos y valores positivos o negativos.

2.4 Rapidez de cambio promedio

Mide cuánto cambia \(f(x)\) por unidad de cambio en \(x\) entre dos puntos.

[f(b) − f(a)] / (b − a)

2.5 Transformaciones

En \(f(x)+k\), la gráfica sube \(k\) unidades si \(k>0\). En \(f(x-h)\), se desplaza \(h\) unidades a la derecha.

g(x) = f(x − h) + k

2.6 Combinación de funciones

Puedes sumar, restar, multiplicar o dividir funciones, respetando el dominio de cada operación.

(f + g)(x) = f(x) + g(x)

2.7 Composición e inversas

La composición sustituye una función dentro de otra: \((f∘g)(x)=f(g(x))\). La inversa deshace la acción de la función original, si existe.

Polinomios y sus gráficas

En la segunda imagen se alcanzan a ver estos apartados del capítulo 3.

3.2 Funciones polinomiales y sus gráficas

Un polinomio suma términos de la forma \(a_nx^n\). Su grado es el exponente mayor con coeficiente distinto de cero.

p(x) = x² − 4x + 3

Las raíces son los valores de \(x\) donde la gráfica corta o toca el eje horizontal.

3.3 División de polinomios

Se puede dividir usando división larga o división sintética (cuando el divisor es lineal de la forma \(x-c\)). Comprueba con:

Dividendo = divisor · cociente + residuo

Funciones trigonométricas: método del triángulo rectángulo

Relaciona los ángulos con las longitudes de los lados de un triángulo rectángulo.

6.1 Medida de un ángulo

Los ángulos se miden en grados o radianes. Una vuelta completa equivale a \(360°\) o \(2π\) radianes.

Radianes = grados · π / 180

Ejemplo: \(90°=π/2\) rad.

6.2 Trigonometría de triángulos rectángulos

Respecto al ángulo elegido, identifica el cateto opuesto, el adyacente y la hipotenusa (el lado más largo).

sen θ = opuesto / hipotenusa
cos θ = adyacente / hipotenusa
tan θ = opuesto / adyacente

6.3 Funciones trigonométricas de ángulos

Las funciones seno, coseno y tangente describen relaciones entre ángulos y lados. Sus valores dependen del ángulo y de la unidad configurada en la calculadora.

tan θ = sen θ / cos θ

Ejemplo: para \(θ=30°\), \(\sin θ=1/2\).

6.4 Funciones inversas y triángulos rectángulos

Las inversas permiten encontrar el ángulo cuando conoces una razón de lados.

θ = sen⁻¹(opuesto / hipotenusa)

Ejemplo: si opuesto/hipotenusa = 0.5, entonces \(θ=30°\) en el triángulo usual.

REGLA PARA RECORDAR

SOH · CAH · TOA

SOH: Seno = Opuesto / Hipotenusa
CAH: Coseno = Adyacente / Hipotenusa
TOA: Tangente = Opuesto / Adyacente
